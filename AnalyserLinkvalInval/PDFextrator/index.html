Extracteurs de Liens PDF_

Extrayez chaque lien, visible ou caché, de n'importe quel PDF.

Plus besoin de chercher manuellement les URLs dans vos documents. Ces outils scannent les PDF en profondeur pour récupérer tous les liens, même ceux intégrés dans du texte comme "cliquez ici".

Télécharger la Suite d'Outils

Deux Outils, Un Objectif

Extracteur Simple

  • Une application exécutable (.exe) légère et rapide.
  • Extrait uniquement les URLs brutes et visibles (ex: `http://exemple.com`).
  • Génère un fichier .txt simple avec un lien par ligne.
  • Parfait pour une récupération rapide et sans fioritures.
  • Dossier : $simple/dist/

Extracteur 'Bizarre' (Complet)

  • La version exécutable (.exe) la plus puissante.
  • Extrait TOUS les liens, y compris ceux cachés dans le texte.
  • Récupère aussi le texte sur lequel le lien est attaché.
  • Génère un fichier .txt structuré pour une meilleure lisibilité.
  • Dossier : $bizzare/dist/

Comment Ça Marche ?

L'utilisation est incroyablement simple. Pas besoin d'installer Python ou des dépendances complexes. Suivez simplement ces étapes :

  1. Après avoir téléchargé et décompressé le pack, naviguez vers le dossier : MES APPLICATION EXE/les extrateurs de lien dans pdf/.
  2. Choisissez la version que vous souhaitez utiliser : $simple (pour les liens visibles) ou $bizzare (pour tous les liens).
  3. Ouvrez le sous-dossier correspondant, puis entrez dans le dossier dist.
  4. Double-cliquez sur le fichier .exe qui s'y trouve.
  5. Une fenêtre de terminal s'ouvrira, vous demandant de glisser-déposer votre fichier PDF. Suivez simplement les instructions à l'écran !

Note importante

Comme ces exécutables ont été créés à partir de scripts, votre système d'exploitation ou antivirus pourrait afficher un avertissement de sécurité. C'est une fausse alerte normale. Les outils sont sûrs.

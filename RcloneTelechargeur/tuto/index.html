Bienvenue !

Ce site présente une collection d'outils que j'ai développés pour automatiser diverses tâches. À l'origine, ce sont des scripts Python, mais pour vous faciliter la vie, je les ai compilés en applications exécutables (.exe). Vous n'avez donc pas besoin d'installer Python pour les utiliser !

Toutes les applications sont regroupées dans un seul dossier. Suivez les étapes ci-dessous pour commencer.

Étape 1 : Téléchargement

Cliquez sur le bouton ci-dessous pour télécharger le dossier compressé MES APPLICATION EXE.zip contenant tous les outils.

Télécharger Tous les Outils (.zip)

Étape 2 : Décompression

Une fois le fichier téléchargé, faites un clic droit dessus et choisissez "Extraire tout..." ou "Décompresser ici" pour obtenir le dossier MES APPLICATION EXE.

Important : Certains antivirus peuvent signaler ces fichiers .exe comme potentiellement dangereux car ils ne sont pas signés numériquement. C'est un comportement normal pour des applications indépendantes. Vous pouvez les utiliser en toute sécurité.

Présentation des Outils

Voici la liste des outils que vous trouverez dans le dossier MES APPLICATION EXE.

LE CONVERTISSEUR DE PY EN EXE

Cet outil vous permet de transformer vos propres scripts Python (.py) en applications exécutables (.exe). C'est la version compilée de mon script original @convertiseur.

  • Utilisation : Exécutez le fichier et suivez les instructions à l'écran dans la console.
  • Chemin du fichier : MES APPLICATION EXE/LE CONVERTISUER DE PY EN EXE/dist/

Analyseur de lien Google Drive

Ce script analyse un lien Google Drive pour vous donner des informations pertinentes sans avoir à l'ouvrir dans un navigateur.

  • Chemin du fichier : MES APPLICATION EXE/analyseur de lien gogole drive/dist/

FiltreImage

À but éducatif, cet outil vous aide à faire un tri rapide de vos photos. Il scanne un dossier que vous lui indiquez, détecte les images potentiellement sensibles (nudité, etc.) et les déplace automatiquement dans un sous-dossier pour que vous puissiez les examiner.

  • Chemin du fichier : MES APPLICATION EXE/FiltreImage/dist/

Globale Tools beta

Une version "tout-en-un" qui regroupe plusieurs de mes outils en une seule interface légère. Idéal pour avoir les fonctions de base sous la main.

  • Chemin du fichier : MES APPLICATION EXE/Globale Tools beta/dist/

Les Extrateurs de liens dans PDF

Ce dossier contient deux versions d'un outil pour extraire tous les liens hypertextes d'un fichier PDF.

  • Dossier $simple : Extrait uniquement les liens visibles (ex: www.google.com).
  • Dossier $bizzare : Extrait tous les types de liens, y compris ceux qui sont "cachés" ou insérés dans du texte (ex: Cliquez ici).

Pour chaque version, l'exécutable se trouve dans son sous-dossier dist.

Rclone Telechargeur

Un outil puissant pour télécharger de gros dossiers ou fichiers depuis Google Drive directement sur votre disque dur, sans passer par la compression ZIP habituelle de Google. C'est beaucoup plus rapide et fiable pour les transferts volumineux.

  • Important : Ce dossier contient non seulement l'exécutable de mon script, mais aussi l'application rclone.exe elle-même, qui est nécessaire à son fonctionnement. Ne la supprimez pas.
  • Chemin du fichier : MES APPLICATION EXE/Rclone telechargeur/dist/

Comment Utiliser les Outils ?

Le fonctionnement est très simple et identique pour presque tous les outils :

  1. Naviguez dans le dossier de l'outil qui vous intéresse (par ex. FiltreImage).
  2. Ouvrez le sous-dossier nommé dist. C'est ici que se trouve toujours l'application.
  3. Double-cliquez sur le fichier .exe pour le lancer.
  4. Une fenêtre de console (un terminal noir) s'ouvrira. Lisez attentivement les instructions et saisissez les informations demandées (par ex. le chemin d'un dossier, un lien, etc.).
Rappel : Pour le "Rclone Telechargeur", assurez-vous que rclone.exe et le fichier .exe de mon script restent bien dans le même dossier dist.

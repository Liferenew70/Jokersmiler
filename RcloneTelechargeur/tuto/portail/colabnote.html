Copier un Dossier Google Drive Partagé

Utilisez ce script optimisé pour Google Colab pour cloner n'importe quel dossier Google Drive partagé, même très volumineux, directement dans votre propre espace Drive.

Comment l'utiliser ?

  1. Ouvrez le site de Google Colab et connectez-vous avec votre compte Google.
  2. Cliquez sur "Nouveau notebook" pour créer un nouvel environnement de travail.
  3. Copiez la totalité du code dans le bloc ci-dessous en utilisant l'icône de copie .
  4. Collez le code dans la cellule de votre nouveau notebook.
  5. Cliquez sur l'icône "Play" (▶️) à gauche de la cellule pour lancer l'exécution du script.
  6. Une pop-up s'ouvrira, vous demandant d'autoriser l'accès à votre Google Drive. Acceptez.
  7. C'est tout ! Le script créera un dossier Copie_Dossier_Ami à la racine de votre Drive et commencera la copie. Vous pouvez suivre la progression directement dans la sortie du notebook.

Le Code Complet


# Étape 1 : Installer les dépendances

import time
import random
from pydrive.auth import GoogleAuth
from pydrive.drive import GoogleDrive
from google.colab import auth
from oauth2client.client import GoogleCredentials

# Authentification
auth.authenticate_user()
gauth = GoogleAuth()
gauth.credentials = GoogleCredentials.get_application_default()
drive = GoogleDrive(gauth)

print("✅ Authentification réussie.")

# Fonction pour tenter une opération avec retries
def try_with_retries(func, *args, retries=5, delay=5, **kwargs):
    for attempt in range(retries):
        try:
            return func(*args, **kwargs)
        except Exception as e:
            print(f"⚠ Erreur : {e}, tentative {attempt+1}/{retries}")
            time.sleep(delay + random.uniform(0.1, 1.0))
    print("❌ Échec après plusieurs tentatives.")
    return None

# Fonction pour copier un fichier (méthode non directe pour éviter les limitations)
def copy_file_robust(drive_instance, file_id, parent_id):
    file_to_copy = drive_instance.CreateFile({'id': file_id})
    file_to_copy.FetchMetadata() # Récupérer les métadonnées (nom, etc.)

    new_file = drive_instance.CreateFile({
        'title': file_to_copy['title'],
        'parents': [{'id': parent_id}]
    })

    # La copie directe via l'API est souvent bloquée, cette méthode est plus fiable
    try:
        content = file_to_copy.GetContentString()
        new_file.SetContentString(content)
        try_with_retries(new_file.Upload, {'convert': True}) # 'convert': True pour les Google Docs
        print(f"📄 Fichier copié : {new_file['title']}")
    except Exception as e:
        print(f"❌ Erreur sur le fichier {file_to_copy['title']}: {e}. Fichier ignoré.")


# Fonction récursive pour copier un dossier
def copy_folder_recursive(source_folder_id, parent_id=None):
    source_folder = drive.CreateFile({'id': source_folder_id})
    try_with_retries(source_folder.FetchMetadata)

    new_folder = drive.CreateFile({
        'title': source_folder['title'],
        'mimeType': 'application/vnd.google-apps.folder',
        'parents': [{'id': parent_id}] if parent_id else []
    })
    try_with_retries(new_folder.Upload)
    print(f"\n📁 Nouveau dossier créé : {new_folder['title']}")

    file_list = try_with_retries(drive.ListFile({'q': f"'{source_folder_id}' in parents and trashed=false", 'maxResults': 1000}).GetList)
    
    if not file_list:
        print("   -> Dossier vide.")
        return new_folder['id']
        
    for file in file_list:
        if file['mimeType'] == 'application/vnd.google-apps.folder':
            copy_folder_recursive(file['id'], new_folder['id'])
        else:
            copy_file_robust(drive, file['id'], new_folder['id'])

    return new_folder['id']

# ================================================
#  ⚠️ MODIFIEZ L'ID DU DOSSIER À COPIER ICI ⚠️
# ================================================
source_folder_id = 'ID_DU_DOSSIER_PARTAGE_ICI'

# Nom du dossier qui sera créé dans votre Drive
destination_folder_name = 'Copie_Dossier_Ami'

# Créer un dossier racine dans ton Drive
root_folder = drive.CreateFile({
    'title': destination_folder_name,
    'mimeType': 'application/vnd.google-apps.folder'
})
try_with_retries(root_folder.Upload)
print(f"📦 Dossier racine '{destination_folder_name}' créé dans votre Drive.")

# Lancer la copie
print("\n🚀 Démarrage de la copie (cela peut prendre plusieurs heures)...")
copy_folder_recursive(source_folder_id, root_folder['id'])

print(f"\n✅ Copie complète terminée ! Retrouvez les fichiers dans votre Drive > {destination_folder_name}")

À Savoir Avant de Commencer

  • Patience est mère de sûreté : Si le dossier est très volumineux (plusieurs dizaines de Go), la copie peut prendre plusieurs heures. Google Colab peut se déconnecter après un certain temps. Si cela arrive, relancez simplement le script. Il reprendra là où il s'est arrêté (note: une gestion de reprise plus avancée serait nécessaire pour une fiabilité parfaite, mais ce script est robuste pour la plupart des cas).
  • ID du Dossier : Pensez à remplacer 'ID_DU_DOSSIER_PARTAGE_ICI' par le vrai ID du dossier que vous voulez copier. Vous le trouverez dans l'URL du dossier (la longue chaîne de caractères après folders/).
  • Sécurité : Ce script ne fait que copier. Il ne modifie ni ne supprime jamais le dossier source de votre ami. Votre authentification est sécurisée et gérée directement par Google.

Présentation des Outils

Rclone Telechargeur

Téléchargez des dossiers volumineux depuis Google Drive sans la compression .zip habituelle, pour des transferts plus rapides et plus fiables. Nécessite l'exécutable Rclone inclus dans son dossier.

Analyseur de Liens GDrive

Fournissez un fichier .txt de liens Google Drive et l'outil les triera automatiquement en deux fichiers : liens_valides.txt et liens_invalides.txt. Fini le gaspillage de temps !

Extracteurs de Liens PDF

Deux versions pour extraire les URLs de vos PDF. Une version simple pour les liens visibles et une version bizzare (complète) pour tous les liens, même ceux cachés dans le texte.

Convertisseur PY en EXE

Transformez facilement vos propres scripts Python .py en applications exécutables .exe portables, comme celles de ce pack. Une version compilée du premier outil de la suite.

FiltreImage

Un outil à but éducatif pour trier rapidement vos photos. Scanne un dossier, détecte les images potentiellement sensibles et les déplace dans un sous-dossier pour vérification.

Globale Tools (Beta)

Une application "tout-en-un" qui regroupe les fonctionnalités de plusieurs outils de cette suite dans une seule interface légère. Parfait pour un accès rapide aux fonctions essentielles.

Structure du Pack & Utilisation

Après décompression, vous obtiendrez l'arborescence suivante. Pour utiliser un outil, allez simplement dans son dossier, puis dans /dist/ et double-cliquez sur le fichier .exe.

MES APPLICATION EXE/
|
|--- analyseur de lien gogole drive/
|    \--- dist/
|         \---  AnalyseurDeLienGoogleDrive.exe
|
|--- FiltreImage/
|    \--- dist/
|         \---  imagefiltrerByDossier.exe
|
|--- Globale Tools beta/
|    \--- dist/
|         \---  GlobalJokerTools.exe
|         \---  rclone.exe (essentiel)
|--- LE CONVERTISUER DE PY EN EXE/
|    \--- dist/
|         \---  ConvertiseurPythonInEXE.exe
|
|--- les extrateurs de lien dans pdf/
|    |--- $bizzare/dist/
|    |    \---  PdfTextLinker.exe
|    \--- $simple/dist/
|         \---  PdfLinkSimple.exe
|
|--- Rclone telechargeur/
|    \--- dist/
|         |---  RcloneTelechargeur.exe
|         \---  rclone.exe (essentiel)
|
\--- (@convertiseur est la version script du convertisseur)

Rappel : Votre système peut afficher un avertissement de sécurité car les fichiers ne sont pas signés. C'est normal, vous pouvez les exécuter sans crainte.
